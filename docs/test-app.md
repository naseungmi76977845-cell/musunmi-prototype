# 수어역 테스트 앱

기준 UI는 Meta Astryx의 실제 React 컴포넌트와 그린·라임 소프트(sage) 테마입니다. 기본 주소는 비교 갤러리 없이 앱 로그인부터 열립니다.

## 확인 흐름

1. `/`에서 로그인 화면과 카카오·Google 버튼을 확인합니다. 현재 이메일 로그인은 화면 흐름 테스트용이며 실제 계정을 인증하지 않습니다. 실제 사용하는 비밀번호를 입력하지 않습니다.
2. 회원가입 → 계정 정보 → 프로필·사용자 유형 → 수어 경험 → 가입 목적 → 약관 → 홈 순서로 이동합니다.
3. 하단 탭에서 홈·사전역(위키 검색)·배움역·소통역·마이페이지를 확인합니다. 배움역 노선의 마지막 역까지 스크롤합니다.
4. 글·질문 작성, 영상 올리기, 내 글·내 영상, 알림, 포인트·프로필 꾸미기, 계정 탈퇴 흐름을 확인합니다. 로컬 데이터는 같은 브라우저에서만 동작하며 다른 기기나 사용자와 공유되지 않습니다.
5. 위키의 수어로 찾기에서 카메라 권한 허용·거부 화면을 확인합니다. MediaPipe 추출과 외부 추론은 별개입니다. 추론 서버 미설정 상태에는 실제 인식 결과가 나오지 않습니다.

## 별도 화면

- `/?view=gallery` — 그림 라인·Astryx 비교
- `/planning/` — PRD·기능명세서·유저플로우·와이어프레임·Astryx 예시·PDF
- `/admin.html` 또는 `/admin` — 로컬 관리 시안. 서버 인증·권한 통제가 연결된 운영 도구가 아닙니다.

## 배포 연결 수용 기준

- Vercel 프로젝트가 GitHub `Hariuncle/sueoyeok`과 연결되어 있고 Production Branch가 `main`입니다.
- `main` 푸시 또는 PR 머지로 새 배포가 시작되고, `npm test && npm run build`가 성공한 버전이 테스트 주소에 반영됩니다.
- PR은 별도 Preview URL에서 확인합니다. 테스트 실패 시 새 버전이 배포되지 않습니다.
- 배포된 `/`에서 Astryx 그린 로그인, 가입 후 홈, 위키 검색, 배움역, 소통역, 마이페이지를 확인합니다.
- 기획서·PDF·관리자 HTML·모델·WASM 정적 파일이 앱 HTML로 대체되지 않고 정상 제공됩니다.

현재 OAuth, 비밀번호 인증·재설정 메일, 공유 DB, 실제 푸시, 외부 수어 추론은 미연결입니다. AI 대화·수어 아바타·얼굴 AI 변경은 문서의 논의필요 범위를 유지합니다. Vercel 배포 자체가 이 기능들을 연결하지는 않습니다.
