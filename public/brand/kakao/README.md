# 카카오 로그인 버튼

- 공식 리소스: https://developers.kakao.com/tool/resource/login
- 파일 원본: https://developers.kakao.com/tool/images/resource/preview/login-complete-ko.svg
- 디자인 가이드: https://developers.kakao.com/docs/ko/kakaologin/design-guide

완성형 한국어 SVG 원본을 변경 없이 사용한다. 가로 확장은 #FEE500 컨테이너로 하고 내부 이미지는 비율을 유지한다. 카카오 자산은 프로젝트의 오픈소스 라이선스와 별개이며 카카오 가이드가 적용된다.

현재 비교 시안에는 카카오 OAuth/앱 키가 연결돼 있지 않다. 버튼은 준비 안내만 표시하며 로그인 상태나 계정 데이터를 만들지 않는다. 실제 연결 시 인가 코드 및 서버 세션 처리를 구현해야 한다.
