# Google 로그인 버튼

- 공식 가이드: https://developers.google.com/identity/branding-guidelines
- G 원본: https://developers.google.com/static/identity/images/g-logo.png
- Google Sans Medium: https://fonts.googleapis.com/css2?family=Google+Sans:wght@500
- 폰트 라이선스 원본: https://github.com/google/fonts/blob/main/ofl/googlesans/OFL.txt

공식 G 이미지의 색상·비율을 유지하고 흰색 버튼, 1px #747775 테두리, #1F1F1F 글자, Google Sans Medium을 사용한다. 한국어 글자는 앱의 Pretendard로 표시한다. 카카오와 같은 너비·높이로 표시한다. Google 브랜드 자산은 프로젝트 오픈소스 라이선스와 별개이며 공식 가이드가 적용된다. 폰트는 동봉한 OFL.txt를 따른다.

현재 시안에는 OAuth 클라이언트와 서버 세션이 연결되지 않았다. 클릭 시 준비 안내만 표시하며 Google 계정 선택창·인증 성공·계정 생성을 흉내 내지 않는다.
