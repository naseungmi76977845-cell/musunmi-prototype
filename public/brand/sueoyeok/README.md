# 수어역

수어를 찾는 여정의 종착역. 열린 역명판 안으로 노선이 들어와 하나의 도착점에서 끝나는 심볼이다. 손 모양이나 실제 수어 동작을 브랜드 기호로 사용하지 않는다.

- `symbol.svg`: 단색 심볼. 앱에서는 CSS mask로 브랜드 색상을 적용한다.
- `app-icon.svg`: 그린·라임 앱 아이콘 및 파비콘.
- `gugu.jpg`: 마스코트 구구. 홈 안내 역무원으로 사용하며 얼굴·색·비율은 원본을 유지한다.
- `src/brand.tsx`: 심볼과 ‘수어역’ 이름을 조합한 공통 로고.
- `src/gugu.tsx`: 구구 이미지와 역무원 모자·명찰 오버레이.

브랜드 표시인 비교 도구·가입·로그인·홈·가입 완료에 적용했다. 위키와 학습 콘텐츠의 손 아이콘은 콘텐츠를 나타내므로 유지한다. 이 적용 범위는 design-lab 모바일 웹 시안이다.
