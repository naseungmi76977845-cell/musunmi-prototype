# 향후 기능 · AI 수어 대화와 한국어 → 수어 아바타

2026-10-22 · 자체 연구개발 · 앱·API 연동 미완료

## 기획 요약
수어역의 향후 학습 기능으로, AI 에이전트와 상황별 대화를 연습하고 한국어 문장이나 AI의 답변을 한국수어 아바타로 확인하는 경험을 추가한다. 배움역에서 익힌 표현을 대화 속에서 반복해 쓰도록 확장하는 방향이다. 가칭은 ‘AI 수어 대화’이며, 배움역 안의 진입점으로 검토한다. 새 하단 탭·가격·출시 일정은 확정하지 않았다.

사용자 요청은 향후 계획을 정리하는 것이다. 이 문서는 현재 구현 완료를 뜻하지 않으며 실제 대화 에이전트, 한국어→한국수어 번역기, 수어 모션·아바타 렌더러는 아직 연결하지 않았다.

## 논의필요 범위
수어 인식·한국어 → 수어 생성/아바타·영상의 AI 얼굴 변경은 sua_research의 양방향·생성 연구와 별도 얼굴 변경 시험을 바탕으로 제품 적용 범위를 논의한다. 자체 연구 결과를 활용하는 방향이며 입력 정합·모델 적용/학습·추론 API·평가·앱 연동의 최종 범위·담당·일정은 확정 전이다.

연구 코드·시험 기록은 존재하지만 앱의 대화/아바타 연동과 제품 품질 검증이 끝난 것은 아니다. 자체 추론 서버 활용안, 지원 표현·품질 기준·모델/좌표 계약·운영 담당·서버 자원·비용·제품화 순서를 논의한다. 대화 에이전트의 턴·상황·힌트 제어와 기반 LLM도 제품 구성 논의에 포함한다.

## 스픽에서 참고하는 경험
스픽의 Speak Tutor에서 참고할 부분은 학습자에게 맞춘 대화와 연습이며, Free Talk에서는 상황·역할을 정해 상대와 주고받고 필요할 때 힌트·다시 시도를 제공하는 흐름을 참고한다. 수어역은 이 대화 연습 구조를 수어 학습에 맞춰 설계한다. 스픽의 기능·캐릭터·콘텐츠를 복제하거나 스픽 API를 연동한다는 의미가 아니다.

근거: [Speak Tutor 공식 안내](https://help.speak.com/en/articles/11396739-what-is-speak-tutor), [Free Talk 공식 안내](https://help.speak.com/en/articles/13182402-free-talk-immersive-roleplay). 스픽의 음성 중심 방식을 수어역의 필수 입력 방식으로 가져오지 않는다. 수어역은 한국어 텍스트 입력을 먼저 제공하고, 음성 입력과 카메라 수어 응답은 별도 단계로 검토한다.

## 두 기능의 역할
| 기능 | 사용자의 목적 | 입력 → 출력 | 다른 기능과의 관계 |
| --- | --- | --- | --- |
| 한국어 → 수어 아바타 | 내가 쓴 말이 수어로 어떻게 표현되는지 이해하기 | 한국어 문장 → 의미 확인·한국수어 표현 계획 → 아바타 동작 | 단독 연습 기능이면서 AI 대화의 출력 엔진 |
| AI 수어 대화 | 배운 표현을 상황 속에서 주고받기 | 상황·목표·사용자 메시지 → AI 답변·힌트 → 수어 아바타와 한국어 자막 | 한국어→수어 아바타 품질 확보 후 연결 |
| 카메라 수어 응답 | 직접 수어로 AI에게 답하기 | 실시간 카메라 → MediaPipe 좌표 → 자체 수어 해석 → 사용자 의미 확인 → AI 답변 | 후속 확장; 현재 수어 검색의 단어 후보만으로 문장 대화가 가능하다고 가정하지 않음 |

현재 수어로 찾기는 수어 입력을 표현 후보로 연결하는 방향이고, 한국어→아바타는 그 반대 방향의 생성 기능이다. MediaPipe 좌표만으로 한국어 문장을 수어 동작으로 만들 수 있다고 가정하지 않는다. 영상 등록 시 선택하는 AI 얼굴 변경(D07)은 촬영 영상의 얼굴 외형을 바꾸는 별도 계획 기능이다. 한국어에서 새 수어 동작을 생성하는 이 아바타 기능과 목적·입력·출력이 다르다.

## 1단계 · 한국어 → 수어 아바타
초기에는 검토한 짧은 생활 표현과 지원 상황부터 다룬다. 예를 들어 한국어 ‘물 한 잔 주세요’를 입력하면, 필요할 때 맥락을 확인하고 검토된 해당 의미의 수어 표현을 아바타로 보여 주는 경험이다. 이 문서는 그 문장의 정답 수어 동작이나 번역을 제시하지 않는다.

| 항목 | 계획 |
| --- | --- |
| 입력 | 한국어 텍스트 우선. 문장이 바뀌면 이전 생성 요청을 취소 |
| 의미 확인 | 생략·다의어·고유명사 등 불명확한 부분을 사용자에게 확인 |
| 번역 | 문장의 의미·맥락을 한국수어 표현 계획으로 변환 |
| 동작 | 검토한 모션 자산 또는 검증된 생성 결과를 아바타에 적용 |
| 화면 | 얼굴·두 손·상체가 함께 보이는 아바타, 대응하는 한국어 자막, 일시정지·반복·느리게·구간 다시 보기 |
| 미지원 | 임의 동작을 만들지 않고 다른 표현 입력·검토된 표현 보기로 안내. 지문자 대체는 적용 기준을 정한 뒤 제공 |
| 연결 | 관련 위키 표현·학습역으로 이동. 저장·재방문 범위는 별도 동의·보관 정책 확정 후 구현 |

한국수어를 한국어 단어 순서대로 이어 붙이는 방식으로 설계하지 않는다. 한국수어의 언어적 특성과 의미를 반영하고 수형·위치·방향·움직임뿐 아니라 얼굴 표정·시선·몸의 표현까지 검토한다. 수어 이해 가능성과 정확성을 아바타의 사실적인 외형보다 우선한다. 한국수어가 한국어와 다른 문법 체계를 가진다는 점은 [국립국어원 안내](https://korean.go.kr/front/page/pageView.do?mn_id=202&page_id=P000300)를 참고한다.

## 2단계 · AI 에이전트와 상황별 대화
초기 상황 후보는 인사·자기소개, 카페 주문, 길 묻기처럼 짧은 일상 대화다. 사용자는 상황과 연습 목표를 고르고, AI는 상대 역할을 맡아 대화를 이어 간다. 가입 시 선택한 수어 경험과 목표를 활용하되, 사용자가 이번 연습의 난이도·자막·힌트 방식을 조정할 수 있게 한다.

배움역 → AI 수어 대화(향후) → 상황·목표 선택 → AI 첫 질문과 수어 아바타 → 사용자 한국어 답변 → AI가 문맥을 이어 답변 → 답변을 한국수어로 변환·재생 → 필요 시 힌트·다시 시도 → 종료·복습의 흐름이다.

| 기능 | 기획 범위 | 처음부터 보장하지 않는 것 |
| --- | --- | --- |
| 대화 이어 가기 | 이전 발화·상황·연습 목표를 참고한 답변 | 어떤 주제든 정확한 자유 대화·실시간 통역 |
| 이해 도움 | 한국어 자막, 느리게·반복, 상황 힌트, 지원 표현 안내 | 모든 수어 변형·사투리 자동 판별 |
| 다시 시도 | 방금 한 응답을 고쳐 대화 이어 가기 | 미검증 자동 점수·순위·학습 완료 판정 |
| 피드백 | 초기에는 텍스트 응답의 의미·상황 적합성과 복습할 표현을 안내 | 텍스트 입력만으로 사용자의 수형·손 방향이 정확하다고 평가 |
| 턴 제어 | 생각할 시간, 일시정지, 응답 중단·재생·재시작 | 수어 의미가 끊겼는데도 완료된 응답으로 저장 |
| 복습 | 동의한 대화 기록과 학습 표현을 다시 보기 | 대화 전체·카메라·좌표의 기본 영구 보관 |

한국어 입력 자체의 아바타 변환과 AI가 생성한 답변의 아바타 변환을 화면에서 구분한다. 사용자는 누가 말한 문장인지와 현재 어떤 동작 구간을 보고 있는지 확인할 수 있어야 한다. 내용 수정·턴 변경 뒤 도착한 오래된 번역이나 모션을 새 답변에 붙이지 않는다.

## 3단계 · 수어로 답하는 양방향 대화
실시간 카메라·MediaPipe 추출 구조를 활용하되, 대화용 수어 해석 서버가 연속 표현·문장·발화 끝을 처리하는지 별도로 검증한다. 현재의 수어 검색용 서버도 아직 준비되지 않았으므로 이 기능은 그보다 뒤의 계획이다.

카메라 수어 응답 → 좌표 시계열 추출 → 자체 추론 서버 의미 후보 → 사용자가 해석 의미를 확인·수정 → AI 대화 에이전트 → 한국어 답변 → 한국수어 번역·모션 → 아바타의 순서로 검토한다. 미검출·낮은 확신·부분 해석에는 다시 보여주기 또는 텍스트 입력을 제공한다. 확신 없는 해석을 정답으로 간주해 대화를 진행하지 않는다.

## 필요한 기술과 콘텐츠
| 구성 | 책임 | 선행 조건 |
| --- | --- | --- |
| 대화 에이전트 | 상황·턴·목표를 유지하고 답변·힌트 생성 | 지원 주제·학습 정책·세션/컨텍스트 계약 |
| 한국어→한국수어 번역 | 의미를 수어 표현 계획으로 변환 | 농인·한국수어 전문가 검토, 번역 기준과 평가 데이터 |
| 모션·아바타 | 표현 계획을 손·얼굴·상체 동작으로 재생 | 허가된 리깅·모션 자산, 구간 전환·표정·손가락 품질 검증 |
| 실시간 입력 해석 | 우리 팀 추론 파이프라인으로 좌표 시계열을 대화 의미로 해석 | 자체 서버 연결, 어휘/문장 범위·입력/응답 규격·발화 구간 합의 |
| 실행 제어 | 턴 ID로 텍스트·번역·모션·자막을 맞춤 | 취소·타임아웃·오래된 응답 제거·실패 복구 |
| 학습·운영 | 검토한 시나리오 제공, 오류 신고·표현 수정·버전 관리 | 콘텐츠 담당과 검토 절차·모델/콘텐츠 버전 추적 |

연구 기준선·후보를 제품용으로 확정하고 자체 번역·추론·렌더링 API를 앱에 연결하는 작업이 남아 있다. 구체적인 제품용 LLM·모델 버전·렌더링 엔진·서버 자원과 API 계약은 확정 전이다. 번역과 모션 생성의 대기 시간·비용·모바일 성능을 측정한 뒤 스트리밍과 캐시 범위를 정한다. 학습 자료·모션·아바타 외형·개인 대화의 사용 권한을 각각 확인하고, 사용자 영상 공개 허락을 AI 학습 허락으로 대신하지 않는다.

| 단계 | 과제 | 완료 기준 |

| 운영 준비 | 품질/비용/보관 정책과 검토 도구 | 오류 표현 수정·버전 관리, 기록 삭제·동의 철회·권한·운영 절차 검증 |

이 기능은 P2 향후 확장으로 분류한다. 현재 MVP의 인증·저장·콘텐츠 검토·실시간 검색 서버·기초 학습을 우선 완성하되 아바타 연구는 별도 실험으로 진행할 수 있다. A의 이해도 검증을 마치기 전 B/C를 학습 완성 기능으로 출시하지 않는다. 수치 목표·가격·예산·출시일은 정하지 않았으며 위 과제를 달성한 것으로 표시하지 않는다.

평가 항목은 농인 사용자·한국수어 전문가가 확인한 의미 전달과 이해 가능성, 지원 상황의 대화 완료, 재시도·오류 신고, 텍스트/자막/동작 불일치, 턴별 지연과 취소 처리, 세션당 비용이다. 자동 점수만으로 수어 정확도를 인증하지 않는다.

## 현재 상태와 출처
이번에 추가한 것은 제품 기획과 논의필요 범위다. 기존 연구 코드·시험 기록을 확인했으며 이 문서 변경으로 새 학습·추론을 실행하거나 앱 메뉴·대화 화면·아바타·서버를 연결하지는 않았다. 위 사용자 흐름은 제품 연결 계획이며 현재 와이어프레임·UI 예시 탭의 구현 화면과 구분한다.

참고한 스픽의 대화 연습 패턴과 수어역의 한국어→수어 아바타 기획은 구분한다. 스픽이 한국수어 아바타를 제공한다는 주장이 아니다. 기본 용도는 학습·연습이며 사람 통역을 대신하는 서비스로 정의하지 않는다.
