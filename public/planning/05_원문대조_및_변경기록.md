## 원문 해석
원문은 2026-10-21 회의 녹취다. 자동 전사의 수업·수학·노인·농민 등은 맥락이 명확할 때 수어·농인으로 정리한다. 수치·시장·경쟁사 발언을 검증된 사실로 재사용하지 않는다. 의도적인 갈등 유발·탈퇴 숨기기 등의 발언은 제품 정책으로 채택하지 않는다. 탈퇴는 찾을 수 있고 취소 가능한 동선을 유지한다.

## 이전 문서에서 갱신한 부분
후속 범위 정정: 사용자의 최신 요청에 따라 수어 인식·생성 및 얼굴 변경 관련 기능을 ‘논의필요 범위’로 표기했다. sua_research의 양방향 기준선·한국어↔포즈 연구/실험 코드와 별도 face-anonymization-test의 실행 기록을 참고하되, 제품 구현 범위·담당·일정을 확정하지 않는다. 연구/시험 기록과 앱 연동 완료를 구분한다. 연구 파일·학습 데이터·원본 영상은 이 기획 사이트에 복사하지 않았다.

2026-10-22 후속 사용자가 얼굴 노출을 원하지 않는 영상 기여자를 위해 AI 얼굴 변경을 넣겠다고 명시했다. 이를 영상 등록의 선택 기능 D07로 반영하고 PRD·기능명세·계획 플로우·TODO를 동기화했다. 선택 → 동의 → 비공개 처리 → 비교 미리보기 → 확인 → 변경본 등록으로 계획하며 실패 시 원본을 자동 공개하지 않는다. 기존 회의의 표정·입모양 등 의미 훼손 우려는 출시 전 품질 검증 조건으로 유지한다. 실제 UI·모델·서버 구현 완료를 뜻하지 않는다.

이전 2026-10-22 문서는 제품 목표와 별도 Expo 체험을 함께 기록했다. v2는 현재 design-lab 웹을 기준으로 5단계 가입·4유형·4경험·4목적, 20역, 질문/운영, 포인트/꾸미기/알림, 같은 브라우저 기록 연동을 반영한다. 기존 장기 요구를 UI 구현만으로 완료 처리하지 않았다.

후속 사용자 정정으로 수어로 찾기를 파일 선택형에서 실시간 카메라 → 기기 MediaPipe 좌표 추출 → 자체 추론 → 결과 표시로 수정했다. 이는 원문 회의의 AI 준비 아이디어를 그대로 확정한 것이 아니라 현재 사용자의 명시적 추가 요구다. record의 영상 선택/보관은 유지한다. 사용자가 자체 추론 서버와 입출력 규격은 아직 없다고 확인했다. 실제 서버 연결은 대기 상태다. 프런트 추출·어댑터 구현과 실서버 추론 완료를 구분한다.

기술 근거는 [Google MediaPipe Holistic 웹 가이드](https://developers.google.com/edge/mediapipe/solutions/vision/holistic_landmarker/web_js)다. 공식 가이드는 얼굴·손·몸의 랜드마크 검출과 카메라 등 영상 프레임 처리를 설명한다. 이를 수어 의미 인식 모델의 제공으로 해석하지 않는다. 이 문서의 전송·결과 스키마와 임계값은 서버 담당과 합의해야 하는 설계 제안이다.

와이어프레임은 실제 앱 레이아웃에 흑백 윤곽선을 적용한다. 별도 UI 예시 · Astryx 탭은 기존 Astryx 컴포넌트와 그린 라임 소프트(sage) 팔레트를 그대로 사용한다. 실제 버튼·SVG·입력·빈 상세를 재사용하며 390×844 뷰포트로 표시한다. 운영 화면은 넓은 데스크톱 프레임이다. 색·그림자·애니메이션을 제거했으므로 컬러 대비·움직임 평가용 자료는 아니다. 화면의 상호작용은 실제 로컬 기록에 반영될 수 있다.

## 미완료를 명확히 남기는 항목
실제 인증/OAuth/메일, 서버 공유·다중 사용자, 수어 인식·얼굴 변환·AI, 푸시, Day1 평가, 운영 접근 통제와 보안 검증, 실제 정책·콘텐츠 검토·스토어 출시는 완료하지 않았다. 통합 화면은 로컬 프로토타입의 현재 UX 검토 자료다.

수어로 찾기의 실시간 카메라·MediaPipe 추출·어댑터는 이번 수정 구현 범위다. 합성 무인 영상으로 실제 Holistic 모델 초기화·추출(365ms, 미검출 빈 좌표) 및 초기화 취소 AbortError를 브라우저에서 확인했다. 응답 검증·안전한 URL·원본/쿠키 미전송·오류 처리 4개와 기존 28개 테스트가 통과했다. Astra가 초기화 취소 경로를 검토했고 수정 후 추가 차단 결함이 없었다. 실제 카메라 하드웨어/권한과 사람 수어의 검출·의미 인식 정확도, 자체 추론 서버 end-to-end는 미검증이다.

## 후속 사용자 요청 · AI 수어 대화와 아바타
2026-10-22 사용자가 스픽처럼 AI 에이전트와 대화하는 기능, 한국어 → 수어 아바타를 향후 계획에 넣어 달라고 요청했다. 이를 원문 회의의 확정 요구나 이미 구현된 기능으로 합치지 않고 P2 기획으로 추가했다. 06번 상세 계획, PRD·기능명세·계획 플로우·TODO를 함께 갱신했다.

스픽 공식 Speak Tutor/Free Talk 문서는 대화·상황 연습 패턴의 참고 자료다. 한국어→한국수어 아바타와 카메라 양방향 수어 대화는 수어역의 계획이다. 제3자 API 사용·제휴·캐릭터 복제·실제 모델 연결을 주장하지 않는다. 한국수어 언어 특성은 국립국어원 안내를 참고하고, 전문가/농인 검증을 선행 조건으로 정했다. 기능 정확도·모델/API·실기기·대화 성능을 새로 시험하거나 구현 완료로 기록하지 않았다.
