## 조건부·후속
AI 얼굴 변경은 영상 등록의 선택 기능으로 계획했다. 아래 품질·데이터·작업 처리 조건을 검증한 후 출시하며 일정은 미정이다. 3D 시점·AI 문장 변환·결제·구독·경쟁형 랭킹은 별도 과제다. 실시간 수어 검색은 이번 구현 대상이며 MediaPipe 좌표 추출과 서버 의미 추론의 수용 기준을 각각 검증한다. 파일 선택이나 준비 화면으로 실제 추론을 완료 처리하지 않는다.

## 수어 검색 모델 담당과 확정할 계약
서버 주소·인증/허용 origin·전송 방식, 좌표의 손/몸/얼굴 구성과 배열 순서·누락/좌우·정규화, 시계열 프레임률·시간창·호출 주기·동시성·역압력, 시퀀스/시간/요청 상관 식별자·버전, 결과 어휘 ID·사전 매핑·신뢰도 임계값·연속 안정 판정, 오류/시간 초과·취소·보관/로그를 합의한다. 결정 전 어댑터 스키마는 제안으로만 표기한다. 카메라 권한 거부·모델 로드 실패·좌표 미검출·미설정 서버·무응답·스키마 오류·늦은 응답·정지 후 응답·화면 이탈을 검증 행렬에 포함한다.

## 회귀 검증 묶음
가입 5단계 왕복과 선택값 보존; 위키→표현→영상→원래 화면; 20역 탐색 하단; 글 CRUD와 새로고침; 영상 재생·삭제·저장 실패; 질문 답변·신고·운영 숨김/복원; 회원 정지/복원; 포인트 중복/부족/재장착; 탈퇴 취소·최종 정리; 320/390px·데스크톱·인쇄를 확인한다. 로컬 통합 통과와 실제 서버·보안 검증은 별도 기록한다.


## P2 · AI 수어 대화와 한국어 → 수어 아바타
| 순서 | 다음 과제 | 검증·완료 기준 |
| --- | --- | --- |
| 1 | 농인·한국수어 전문가와 초기 상황/표현·평가 세트 선정 | 지원 범위·검토 책임·권리·평가 기준 확정 |
| 2 | 한국어 의미→한국수어 번역→아바타 연구 | 검토된 의미 전달, 손·얼굴·몸·모션 전환 품질, 미지원/실패 안내 |
| 3 | 텍스트 응답 기반 상황별 AI 대화 베타 | 문맥·힌트·재시도·복습, 턴별 자막/동작 일치와 취소·재연결 |
| 4 | 카메라로 수어 응답하는 양방향 확장 | 연속 문장·발화 구간 해석, 의미 확인/수정, 실기기·텍스트 대안 |
| 5 | 운영·비용·보관 정책과 오류 수정 도구 | 버전 관리, 이해도·지연·실패율·비용 측정, 동의 철회·삭제 검증 |

기존 MVP와 실시간 검색 서버 완성을 우선하며 아바타 연구는 별도 실험으로 병행할 수 있다. 수치 목표·가격·출시일은 미정이다. 영상 등록 시 선택하는 AI 얼굴 변경(D07)과 한국어 → 수어 아바타 생성을 별개의 과제로 관리한다. 연구 코드·시험과 별개로 실행 화면·모델·서버의 앱 연동은 아직 완료하지 않았다.
