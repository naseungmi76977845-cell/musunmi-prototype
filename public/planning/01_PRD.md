# 수어역 PRD

2026-10-22 · v2 · 현재 웹 프로토타입과 출시 목표를 구분한 제품 기준

## 제품 정의
수어를 찾고, 배우고, 기록하며 서로 묻고 답하는 참여형 수어 위키다. 사전역·배움역·소통역·마이페이지를 하나의 동선으로 연결한다. 이번 기준 구현은 design-lab 웹 앱이다. 이전 Expo 앱 현황 문서는 별도 구현의 기록이며 이 웹 앱 완료 근거로 사용하지 않는다.

## 문제와 사용자
입문자는 빠른 손동작과 방향을 이해하기 어렵고, 기존 단어 검색으로 해결하지 못하는 질문이 있다. 수어 사용자는 자신의 표현과 맥락을 나누고 싶다. 운영자는 표현 차이와 유해 콘텐츠를 구분하면서 참여를 유지해야 한다.

가입 화면의 사용자 유형은 농인·청인·수어통역사·기타 4종이다. 수어 경험은 처음이에요·조금 알아요·어느 정도 할 수 있어요·익숙하게 사용해요 4단계다. 목적은 배우기·모르는 수어 찾기·아는 수어 나누기·소통하기를 복수 선택한다. 이 선택은 자기소개이며 전문 자격이나 정확성 인증이 아니다. 공개 표시 범위와 별도의 신원·자격 검증은 미결이다.

## 제품 목표와 지표
첫 사용자가 필요한 표현에 도달하고, 맥락을 확인하고, 모르는 표현을 질문하거나 자신의 영상을 남길 수 있게 한다. 학습은 짧고 반복 가능한 성취 경험을 목표로 한다. 초기 제한 베타에서 검색 후 재생률, 검색 0건 비율, 첫 영상 등록 완료율, 질문 응답률, Day 1 완료율, 7일 재방문, 미처리 신고 수·처리 시간을 측정한다. 목표 수치는 아직 정하지 않았으며 현재 웹 앱에 분석 수집 서비스는 연결하지 않았다.

## MVP와 후속
P0는 실제 인증·권한·저장소, 검토된 초기 콘텐츠, 업로드 실패 복구, 신고·운영, 삭제 처리, 접근성이다. 수어로 찾기는 실시간 카메라 기반으로 구현하며 자체 추론 서버 연결을 별도의 통합 조건으로 둔다. P1은 출시 범위 확정 후 Day 1 5문항, 대댓글·댓글 공감, 보상 원장, 알림 동기화를 연결한다. AI 얼굴 변경은 영상 등록 시 선택하는 기능으로 계획한다. 수어 의미 보존·처리 시간·비용 검증은 출시 조건이며 일정은 미정이다. 자유 시점 3D, AI 문장 변환, 결제·구독·랭킹 경쟁은 후속 검토다.

20역 노선은 현재 탐색 UI이며 20개 강의 또는 학습 완료·평가 구현으로 세지 않는다. 수어로 찾기는 실시간 카메라 → 기기 내 MediaPipe Holistic으로 좌표 추출 → 자체 추론 서버 처리 → 결과 표시의 구조다. MediaPipe는 손·몸·얼굴 랜드마크를 검출하며 그 자체가 수어의 의미를 판별하는 모델은 아니다. 원본 영상 업로드를 기본 경로로 사용하지 않고 좌표는 세션 메모리에서 일시 처리한다. 서버 주소와 정확한 모델 계약이 제공되지 않아 실제 서버 추론·인식 정확도는 아직 검증하지 않았다. 입력 동영상 파일 선택은 수어 기록 record 기능에만 유지한다.

## 출시 수용 기준
서버가 사용자별 소유권과 운영 역할을 강제하고 비밀번호·토큰을 안전하게 다뤄야 한다. 업로드 취소·재시도·용량 초과·네트워크 단절을 복구해야 한다. 검토된 영상·학습 정답·해설을 확보해야 한다. 신고 유지·숨김·복원과 작성자 안내·이의 처리, 탈퇴·보관/삭제, 모바일·키보드·화면낭독 검증을 완료해야 한다. 현재 프로토타입을 이 조건을 충족한 출시본으로 선언하지 않는다.


## 향후 P2 · AI 수어 대화와 한국어 → 수어 아바타
스픽의 AI 튜터·상황별 대화 경험을 참고하여 배움역의 학습 표현을 대화로 연습하는 기능을 계획한다. 한국어 문장 또는 AI 답변을 한국수어 아바타로 보여주는 출력 기능을 먼저 검증하고, 이를 상황별 AI 에이전트와 연결한다. 현재 기능 구현이나 스픽 서비스 연동을 뜻하지 않는다.

초기 입력은 한국어 텍스트이며 한국어 의미 확인 → 한국수어 표현 계획 → 검토된 모션/아바타 → 자막·느리게·반복으로 구성한다. 다음 단계에서 상황·목표 선택, 맥락을 유지한 AI 응답, 힌트·다시 시도·복습을 추가한다. 카메라 수어 응답은 연속 문장 해석과 사용자 의미 확인을 검증한 후의 확장이다. 현재 MediaPipe 추출이나 단어 검색을 문장 번역·수어 생성 기능으로 간주하지 않는다.

한국어 단어를 일대일로 붙이는 방식 대신 한국수어 의미·문법·얼굴/몸 표현을 검토한다. 농인·한국수어 전문가의 이해도 검증을 통과한 지원 상황부터 제공한다. 번역·모션·대화는 논의필요 범위로 두며, 연구 후보의 제품 적용 범위·담당·API 계약·비용·보관 정책·출시 일정은 미정이다. 상세 기획은 ‘향후 · AI 수어 대화’ 탭과 06번 문서에 정리한다.
