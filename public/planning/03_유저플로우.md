# 수어역 유저플로우

2026-10-22 · v2 · 실제 화면 ID와 복귀·예외 동선

## 가입과 계정
signup → profileSetup → knowledge → purpose → terms → welcome → home. signup은 1/5, 프로필 2/5, 경험 3/5, 목적 4/5, 약관 5/5다. 유형·경험은 단일 선택, 목적은 복수 선택이다. 입력 오류는 같은 단계에 남고 필수값을 보완한다. 약관 상세 policy를 열고 돌아와 동의한다. login ↔ signup, login → recover → login이 보조 동선이다. 소셜 로그인·복구 메일은 준비 안내에서 끝난다.

## 수어 검색 · 글자로 찾기
home의 수어 검색 또는 wiki → 표현명/뜻 설명/분류/초성 입력 → 검색 결과 수·목록 → term → 뒤로 → 원래 검색 화면이다. 분류·저장 필터·가나다순 정렬을 함께 사용할 수 있다. 결과 0건 → 검색어 수정 또는 전체 표현 보기로 복귀한다. 검색어 지우기는 입력 조건만 제거하고, 전체 표현 보기는 검색·분류·저장 필터를 초기화한다. 질문 작성은 위키의 별도 질문 영역에서 시작한다.

## 탐색과 기여
home 또는 wiki → 검색/분류 → term → 연관 term 또는 record → 영상 선택·정보·권리 확인 → collection → videoDetail. 상세에서 뒤로 가면 직전 표현/영상·원래 진입 화면으로 돌아간다. 저장한 표현은 profile → collection에서 다시 연다. record의 촬영본 선택·보관은 실시간 수어 검색과 별도 동선이다.

영상 없는 표현은 빈 상태에서 첫 기록으로 연결한다. 영상 미선택·형식/용량 오류·권리 미동의는 저장 전 처리한다. 영상 삭제 후 선택 상태·알림 참조를 정리한다. 공개 서버 전송과 얼굴 변환은 이 동선에 연결되지 않았다.

## 영상 등록 · AI 얼굴 변경 (계획)
영상 선택 → AI 얼굴 변경 선택 → 처리 동의 → 비공개 처리 대기/진행 → 변경본 미리보기·원본 비교 → 본인 확인 → 변경본 등록이다. 선택하지 않으면 일반 등록으로 진행한다. 현재 로컬 record 동선에 이 기능이 구현된 것은 아니다.

처리 실패/품질 미달 → 재시도 또는 비공개 임시 보관/취소. 미리보기에서 취소하거나 화면을 떠나면 공개하지 않는다. 취소 후 늦은 작업 결과는 등록하지 않는다. 원본 공개로 전환하려면 사용자의 명시 선택을 다시 받으며 원본을 대체 공개하지 않는다.

## 실시간 수어로 찾기
wiki → signSearch → 카메라 권한 안내·사용자 시작 → 기기 카메라 미리보기 → MediaPipe Holistic 랜드마크 추출 → 좌표 시계열을 자체 추론 서버로 전달 → 후보/인식 결과 → 사전 표현 연결이다. 좌표 추출은 수어 의미 인식이 아니다. 서버 주소·입출력 규약이 미제공이므로 실제 추론 성공은 아직 확인하지 않았다.

카메라 거부·미지원·모델 로드 실패·좌표 미검출은 재시도 또는 텍스트 검색으로 연결한다. 서버 미설정·실패·미확신에는 결과를 꾸며 표시하지 않는다. 정지/뒤로/화면 이탈 → 카메라 트랙 종료·추출 루프 종료·요청 취소·좌표 메모리 해제 → wiki/이전 화면이다. 새 세션과 맞지 않는 늦은 응답은 무시한다. 마이크 권한은 불필요하며 원본 영상 업로드를 기본으로 하지 않는다.

## 질문과 운영
wiki 질문 영역 → questions → questionCompose → question → 답변/신고. 표현에서 질문을 시작했다면 표현 맥락을 전달한다. 선택 질문 없이 question URL로 들어가면 빈 상세다. 운영자는 admin questions/reports → 상세 → 확인 → 숨김/복원/검토 완료 → 앱 질문 목록을 확인한다. 숨김은 복원 가능하며 신고가 곧 자동 삭제를 뜻하지 않는다.

## 배움역
learn → 일상선 20역 탐색 → 선택한 term → 뒤로 → learn. 첫인사역부터 부탁역까지 하나의 긴 노선이다. 스크롤 아래의 역도 같은 상세 동선을 쓴다. 현재는 역 탐색이며 정답 평가·학습 완료 판정을 하지 않는다. 향후 Day 1은 시작 → 영상 → 5문항 → 각 정오답·해설 → 결과 → 복습으로 별도 구현한다.

## 소통역
community → compose → post → 댓글/공감/스크랩 → community. 본인 글은 post → compose(수정) → post, 삭제 후 community로 돌아간다. profile → collection의 내 글·스크랩에서도 상세를 연다. 서버 소유권과 동시 수정, 대댓글·댓글 공감·첨부는 후속이다.

## 내 활동과 탈퇴
profile → profileSetup(수정) → knowledge/purpose → profile. profile → points → 활동 화면 → 포인트 확인 → wardrobe → 구입/장착 → profile. notifications → 활동 원문 → 직전 화면으로 복귀한다. settings → account → withdraw → withdrawConfirm → withdrawDone → signup이며 최종 실행 전 취소가 가능하다. 현재 로컬 체험 데이터 정리이고 실제 계정 재인증·서버 탈퇴와 구분한다.

## 운영 연동
앱에서 생성한 로컬 회원·글·영상·질문 → 동일 origin 저장소 → admin 목록 → 정지/숨김 확인 → 앱에서 변경 확인 → 복원 확인이다. 콘솔은 같은 브라우저 데이터만 관리한다. 사용자 역할·다중 기기·실제 운영 접근 제어를 보장하지 않는다.

## 플로우 그림 읽기
통합 HTML의 유저플로우 탭에는 위 동선을 노드와 화살표로 표시한다. 와이어프레임 탭은 그 노드에 대응하는 실제 앱을 흑백 윤곽선으로 보여준다. UI 예시 · Astryx 탭은 같은 화면을 그린 라임 소프트 컬러로 보여주며 주요 화면·기능별 묶음으로 전환할 수 있다. 상세의 빈 상태도 현재 구현의 일부이며 내용을 꾸며 채우지 않는다.


## 향후 · 한국어 → 수어 아바타
배움역의 아바타 연습 진입(향후) → 한국어 문장 입력 → 모호한 의미 확인 → 한국수어 번역/표현 계획 → 모션·아바타와 한국어 자막 → 느리게/반복·위키 연결. 미지원·생성 실패는 다른 표현 입력 또는 검토된 표현으로 이동한다. 문장을 수정하면 이전 요청을 취소하고 늦게 도착한 아바타는 표시하지 않는다.

## 향후 · AI 수어 대화
배움역 → AI 수어 대화(향후) → 상황·목표 선택 → AI 질문과 수어 아바타 → 사용자 한국어 텍스트 답변 → 맥락을 유지한 AI 답변 → 한국수어 변환·아바타 → 힌트/다시 시도 → 종료·동의한 내용 복습이다. 초기에는 마이크·카메라가 필수 입력이 아니다.

후속 카메라 응답은 권한·시작 → 기기 좌표 추출 → 자체 연속 수어 해석 → 사용자가 해석 의미 확인/수정 → AI 대화로 이어진다. 낮은 확신·미검출에는 다시 보여주기 또는 텍스트 대안을 제공한다. 이 세 동선은 계획이며 현재 앱에서 실행되지 않는다.
