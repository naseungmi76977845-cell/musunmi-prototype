## 영상 등록 · AI 얼굴 변경
얼굴 노출을 원하지 않는 기여자를 위한 선택 기능이다. 등록 단계의 ‘AI 얼굴 변경’은 기본 해제로 두고, 선택하지 않으면 일반 영상 등록 경로를 따른다. 현재 앱은 영상 파일을 로컬에 보관하며 얼굴 변경 UI·연구 모델·처리 서버는 아직 앱에 연결하지 않았다. 아래는 향후 구현 계약이다.

| 단계 | 기능·수용 기준 |
| --- | --- |
| 선택·동의 | 영상 선택 후 AI 얼굴 변경 선택. 처리 목적·전송 대상·원본 보관 기준을 확인한 후 시작. 영상 공개·모델 학습 동의와 구분 |
| 처리 | 비공개 원본 → 변환 작업. 대기·처리 중·완료·실패·취소 상태를 구분하고 실제 진행 정보만 표시. 중복 등록과 취소 후 늦은 완료 결과 반영 차단 |
| 결과 확인 | 본인만 원본/변경본을 비교 재생하고 표정·눈썹·시선·입모양과 얼굴 앞 손동작을 확인. 마음에 들지 않으면 재시도 또는 취소 |
| 등록 | 사용자가 변경본을 확인한 뒤 해당 파일만 공개 등록. AI 변경 영상임을 표시하고 표준 표현·정확성 인증으로 오해하지 않게 함 |
| 실패·이탈 | 원본을 대신 자동 공개하지 않음. 비공개 임시 보관·재시도·삭제/취소 경로 제공. 원본 공개로 전환하려면 별도 명시 선택 필요 |
| 품질 | 얼굴 외형 변경 중에도 수어 의미·표정·입모양·손/몸·재생 시간/프레임 연속성이 유지되는지 농인·한국수어 전문가와 검증. 품질 미달 결과는 공개 차단 |
| 데이터 | 원본과 변경본의 접근 권한 분리, 원본 공개 URL 차단, 임시 파일·작업 취소·탈퇴/삭제 시 정리 기준 확정. 얼굴 변경만으로 음성·배경 등을 포함한 완전한 익명성을 보장한다고 표시하지 않음 |

얼굴 변경 파이프라인과 처리 API는 논의필요 범위다. 별도 로컬 시험을 바탕으로 제품 적용 범위·담당·모델/외형·처리 위치·예상 처리 시간·비용·재시도 한도·보관 기간을 논의한다. 실시간 수어 검색의 MediaPipe 추출이나 한국어 → 수어 아바타 생성과 별도 기능으로 관리한다.

## 저장·권한 경계
회원·프로필·커뮤니티 글·질문 메타데이터는 같은 origin 브라우저 저장소를 공유한다. 영상 Blob은 IndexedDB를 사용한다. 화면과 운영 콘솔이 같은 로컬 기록을 바라보는 구조이며 서버 DB·미디어 CDN이 아니다. 댓글·공감·스크랩·북마크·최근 표현·포인트·꾸미기·활동 알림은 현재 화면 인스턴스의 메모리 상태이며 새로고침·다른 프레임에서 그대로 이어지지 않는다. 회원/글/영상 저장과 구분해 검토한다. 비밀번호는 실제 인증 정보로 저장하지 않는다. 임의로 로컬 저장소를 바꿀 수 있으므로 본인·운영자 표시를 보안 권한으로 보지 않는다. 운영 숨김은 복원 가능한 상태 전이이고 사용자 삭제·탈퇴와 다르다.

회원 레코드는 가입 완료·프로필 수정·첫 게시 기여 시 생성한다. 정지된 회원은 작성이 제한되고 작성한 콘텐츠는 비노출된다. 단순 화면 초기화로 새 식별자를 발급하여 정지를 우회하지 않는다. 탈퇴 시 질문 정리의 실패 복구를 준비하고 영상 파일 정리 준비와 메타데이터 정리를 수행한다. 탈퇴한 회원은 닉네임·이메일·유형·경험·목적 등 개인 필드를 지우고 탈퇴 상태의 이력만 남긴다. 탈퇴 뒤 새 가입은 새 로컬 식별자를 사용한다. 이는 동일 브라우저 안의 상태 관리이며 실제 신원·계정 차단을 보장하지 않는다.

## 상태와 오류
공통 상태는 초기 로딩, 정상, 0건, 입력 오류, 저장 실패, 없거나 접근 불가능한 상세, 준비 중이다. 업로드의 서버 대기/처리/실패/재시도·재인증·세션 만료·실시간 충돌은 출시 구현 대상으로 남긴다. 예시 데이터로 빈 상태를 채우거나 미구현 AI·메일·공개 접수를 성공으로 표시하지 않는다.

## 수어 검색
수어 검색은 핵심 기능이며 두 가지 입력 경로를 제공한다. 글자로 찾기는 한국어로 원하는 수어 표현을 조회하고, 수어로 찾기는 사용자의 실제 수어 동작으로 후보 표현을 찾는다. 영상 기록·질문 작성·향후 한국어 → 수어 아바타와 구분한다.

| 경로 | 검색 대상·처리 | 현재 구현과 잔여 |
| --- | --- | --- |
| 글자로 찾기 · D01 | 표현명·뜻 설명·분류의 부분 일치, 초성만 입력하면 표현명 초성 일치. 공백·대소문자 정규화 | 샘플 표현 20개에서 동작. 전체 위키 데이터·서버 검색은 미연결 |
| 결과 탐색 · D01/D02/D06 | 결과 수·목록, 분류·가나다순·저장 필터, 표현 상세·최근 본 표현 | 로컬 동작. 0건이면 안내와 전체 표현 보기, 저장/최근 기록은 새로고침 후 유지되지 않음 |
| 수어로 찾기 · D05 | 실시간 카메라 → 기기 MediaPipe 좌표 → 자체 추론 서버 의미 추론 → 후보 표현 → 위키 상세 | 카메라 화면·추출 구조·서버 어댑터 구현. 자체 추론 서버가 없어 실제 의미 검색은 아직 불가 |

글자 검색의 현재 수용 예시는 ‘안녕’으로 ‘안녕하세요’를 찾고, ‘ㅇㄴㅎㅅㅇ’로 같은 표현을 찾으며, 없는 검색어는 0건으로 표시하는 것이다. 자동완성·오타 교정·동의어 확장·인기 검색어는 현재 구현 범위가 아니다.

## 실시간 수어 검색 계약
입력은 사용자가 허용한 실시간 카메라 영상이다. 마이크는 요청하지 않는다. 기기에서 MediaPipe Holistic으로 손·몸·얼굴 좌표를 추출하고 자체 추론 서버에는 합의된 좌표 시계열만 보낸다. 기본 경로에서 원본 영상·음성·얼굴 이미지를 업로드하거나 좌표를 영구 보관하지 않는다. 개발/운영 로그에도 좌표 전체를 기본 복제하지 않는다. 랜드마크 추출 성공과 수어 의미 인식 성공은 서로 다른 상태다.

전송 규약은 제안·미확정이다. 각 프레임의 단조 증가 타임스탬프와 시퀀스, 요청/응답 상관 식별자, 입력 스키마 버전을 포함하는 방향을 제안한다. 손/몸/얼굴의 입력 배열 순서·누락값·좌우 기준·영상/월드 좌표·정규화, 프레임률·시간창·전송 주기·동시 요청 수와 전송 방식은 모델 담당과 합의해야 한다. 추출 스케줄과 서버 응답의 속도가 다를 때는 대기열을 제한하고 오래된 프레임/응답을 버리는 역압력 정책을 둔다. 정지·화면 이탈 시 카메라 트랙·추출 루프를 종료하고 진행 중 요청을 취소하며 늦게 도착한 응답을 반영하지 않는다.

응답의 후보 어휘 ID·신뢰도·최종/중간 판정 형식, 지원 어휘와 사전 ID 매핑, 신뢰도 임계값·연속 안정 판정 기준도 미결이다. MediaPipe 검출 신뢰도와 서버 수어 분류 신뢰도를 같은 값으로 취급하지 않는다. 미설정·시간 초과·잘못된 응답·모르는 어휘·낮은 신뢰도에는 인식 실패/미확신을 안내하고 텍스트 검색으로 이동할 수 있게 한다. 추론 엔드포인트 없이 샘플 단어를 인식 결과로 표시하지 않는다. 실제 카메라·좌표 추출·서버 통합의 통과 여부는 실행 검증 뒤 기록한다.

## 검증 행렬
| 시나리오 | 기대 결과 | 확인 수준 |
| --- | --- | --- |
| 가입 필수 누락 / 선택 마케팅 미동의 | 필수 차단 / 선택 동의 없이 진행 | UI 시나리오 확인 대상 |
| 등록 → 새로고침 → 내 목록 → 운영 목록 | 같은 브라우저 기록과 파일 유지 | 통합 브라우저 확인 대상 |
| 회원 정지 → 복원 | 상태 변경·복구·로컬 범위 확인 | 통합 브라우저 확인 대상 |
| 글·영상 숨김 → 앱 재확인 → 복원 | 비노출과 재노출 일치 | 통합 브라우저 확인 대상 |
| 삭제 후 상세·알림·뒤로 가기 | 삭제 대상을 다시 표시하지 않음 | 통합 브라우저 확인 대상 |
| 포인트 중복·잔액 부족·재장착 | 중복 지급·음수 잔액·재구매 없음 | 단위 테스트 대상 |
| 수어 검색 카메라·중단 | 권한 거부·미지원·좌표 미검출 처리, 중단/이탈 시 트랙·루프·요청 종료 | 구현 후 UI·기기 확인 대상 |
| 수어 검색 서버 계약 | 순서/좌표계/누락값·전송창·역압력·식별자·늦은 응답, 어휘/임계값 합의 | 계약·실서버 통합 미확인 |
| 수어 검색 미설정·소셜 로그인·복구 | 가짜 성공 없이 미설정/준비 상태 | UI 확인 대상 |
| 390px·320px·키보드·모달·프린트 | 가로 잘림·포커스 유실 없음 | 렌더링 확인 대상 |

이 표는 수용 기준이다. 실제 실행한 검증 결과는 변경 작업의 결과 보고와 검증 기록으로 별도 제시하며 표의 존재만으로 통과를 주장하지 않는다.
